# Bookerang v0.4 recovery

The earlier source archive is unavailable. This repository is a recovery checkpoint, not the previously tested build.

## Agreed scope
- Java 21, Spring Boot, Spring GraphQL; PostgreSQL/PostGIS.
- Next.js web and React Native/Expo for iOS and Android; shared GraphQL operations.
- Invite-only adult pilot; one-tap location, approximate distance, book listings, free lending or optional offline rentals.
- Borrow request, owner acceptance/decline, cancellation, return, private request-scoped text chat, blocking and reporting.
- No in-app payments, commissions, mandatory community membership or continuous location tracking.
- Never disclose precise location or contact information automatically.

## Remaining work
Recover or implement backend resolvers, database migrations, authentication, shared client and three platform experiences. Enforce authorization, blocking and atomic reservation transitions server-side. Reports require manual review. No real-time subscriptions or push notifications are assumed implemented. Full backend compilation, database integration, device tests, security review and pilot readiness are pending. Do not deploy to real users yet.
